# Taches -- Station LTD / Toolbox Jacques Noir

Ce dossier contient les demandes et idees de fonctionnalites futures pour le projet.

## Comment creer une tache

1. Copier le fichier `_TEMPLATE.md`
2. Le renommer selon le sujet (ex: `lotto-tombola.md`)
3. Remplir les champs du template
4. Mettre le statut a "A faire"

## Types de traitement

| Type            | Description                                              | Exemple                          |
|-----------------|----------------------------------------------------------|----------------------------------|
| Developpement   | Necessite un module code dans l'application              | Systeme de lotto/tombola         |
| Analyse         | Necessite une reflexion, un calcul ou une estimation     | Estimation de stock via captures |
| Strategie       | Necessite des recommandations ou un plan d'action        | Strategie de vente optimale      |
| Reference       | Documentation pure, pas d'action technique               | Reglement du serveur             |

## Statuts

- **Idee** : concept non detaille
- **A faire** : tache definie, prete a etre traitee
- **En cours** : travail en cours
- **Termine** : traitement finalise
- **Annule** : tache abandonnee
